Two Towers and Beyond

A unified task-and-motion-planning system for robotic block manipulation, connecting symbolic PDDL planning with physics-based execution, replanning, and goal verification.

View code View video All projects

This project builds a complete TAMP pipeline for arranging colored blocks into goal structures. The system abstracts the current scene into symbolic predicates, generates a PDDL problem, solves it with Pyperplan, executes manipulation primitives in Genesis, and replans after physical state changes.

The unified demo supports multiple block-building goals, including two-tower structures, single stacked towers, bonus tall towers, and an extended 18-block yellow-cross plus green-square configuration.

My Work

Planning, execution, verification, and physics debugging.

  • Built a unified demo path so every goal configuration runs through the same shared codebase.
  • Selected A* for optimal plans on small goals and enforced hill climbing for the larger goal variants.
  • Implemented closed-loop execution that replans after every action until the goal is verified.
  • Added headless recording and verification paths so simulation runs produce videos, logs, and measurable success checks.
  • Debugged manipulation failures in gravity compensation, grasp attachment, finger control, descent, IK convergence, and putdown target selection.
